Questions and Answers

How do I plot a function?

Enable a built-in function in the Draw Functions palette, or enter a formula in the y = field and check Draw Custom Function. Use Add... to create a separately labeled curve.

Can I plot a circle, spiral or implicit equation?

Yes. Add a Parametric, Polar or Implicit curve. For example, use cos(t) and sin(t) for a unit circle, or x^2+y^2-1 for its implicit form.

Are angles in degrees?

Expression functions use radians. Triangle angle values are displayed in degrees. Convert degrees to radians in a formula by multiplying by pi/180.

How do I return to the original view?

Right-click in the graph. To change the original range, open Draw > Draw Options....

Why does my curve contain gaps?

Values outside the function's domain are not plotted. For instance, sqrt(x) is undefined for negative x and 1/x is undefined at zero.

Does zooming recalculate my custom function?

No. The quick custom y=f(x) expression is sampled over its configured x-range. Set a wider range in the Draw Functions palette to sample more x values.

What is stored in a document?

GraphDrawer saves display options, built-in function visibility, custom curve definitions and geometric objects. Curve data is recalculated when the file is opened.

Where is the manual?

Choose Help > Help Contents or press F1. The CHM file is installed in the application's Help subfolder.

Tips

  • Use parentheses to make the intended order of operations clear.
  • Use 2*pi for a full rotation in curve range fields.

Limitations

GraphDrawer does not perform symbolic simplification, differentiation or integration. Its plots are samples, not proofs of function behavior.

Examples

For a full unit circle, add a parametric curve with x(t)=cos(t), y(t)=sin(t), and range 0 to 2*pi.
