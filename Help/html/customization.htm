Description

Use Draw Options and the curve dialogs to tailor the coordinate view, axis appearance, colors, scale and displayed content.

How to Use

  1. Open Draw > Draw Options....
  2. Set the coordinate limits, axis and tick visibility, colors and thickness.
  3. Select a scale mode and enter its related values.
  4. Click OK. The view returns to the configured range.

Axes and Appearance

Toggle coordinate axes, tick marks and tick labels independently. Choose the axis color and line thickness, and select a background color. Tick spacing is chosen automatically from readable intervals; the interval field controls the requested subdivision density.

Coordinate Range

Enter minimum and maximum values for X and Y. The minimum must be lower than the maximum. After applying the dialog, right-click in the graph at any time to reset the view to these limits.

Scale Modes

ModeDescriptionUse
Equal ScaleOne unit uses the same screen distance on both axes. The shorter range is expanded to preserve the aspect ratio. Geometry where circles and angles should appear undistorted.
Free ScaleSet separate X and Y centimetres-per-unit values. Comparing quantities with different visual scales.
LogarithmicChoose Log X / Linear Y, Linear X / Log Y, or Log X / Log Y. Data spanning multiple orders of magnitude.

For a log axis, values must be positive. If a configured lower limit is not positive, the application clamps it to a small positive value for display.

Curve and Geometry Appearance

Each user-defined curve has a label, color and independent visibility checkbox. Select a curve in the palette to edit or remove it. Geometric objects can be shown or hidden individually; triangle labels and construction lines are selected in the triangle dialog.

Tips

  • Choose Equal Scale when comparing geometric shapes.
  • For exponential growth, try Linear X / Log Y; for power laws, try Log X / Log Y.
  • Use a high-contrast axis and curve color against the selected background.

Limitations

Logarithmic scales cannot represent zero or negative values. Free Scale values are positive scale factors. Zooming and panning adjust the current view; right-click restores the configured limits.

Examples

  • To display a unit circle without distortion, choose Equal Scale and plot x(t)=cos(t), y(t)=sin(t).
  • To inspect a function growing exponentially, enable Log Y and use positive y-axis limits.

Notes: Draw Options are saved with the document. The view's temporary zoom and pan position is separate from the configured range.

Tips: If a graph appears stretched, verify that the scale mode is appropriate and check both axis ranges.

Warnings: A logarithmic range that includes non-positive values is adjusted for display and may not match the values you entered.
