Description

This topic walks through plotting functions, creating curves, navigating the view, saving documents and printing. The main window displays the coordinate plane; the Draw Functions palette controls graphs.

How to Use

  1. Launch GraphDrawer. The Draw Functions palette is shown by default.
  2. Check one or more built-in functions, or enter an expression in the y = field and enable Draw Custom Function.
  3. Use Add... to create a curve with its own label and color.
  4. Choose Draw > Draw Options... to set the coordinate range and display style.
  5. Choose File > Save or Save As... to save the current document.

Plot Built-in Functions

The Draw Functions palette contains fourteen independent checkboxes: sin, cos, tan, cot, exp, ln, inverse trigonometric functions, and hyperbolic functions. Check a function to display it and clear the checkbox to hide it. The view redraws as selections change.

For a user-defined expression, enter an expression in x in the y = field. The adjacent range fields specify the sampling interval for this quick custom plot.

Enter a Custom Expression

  1. Type an expression such as x^2 - x + 1 into the y = field.
  2. Set the x-range if needed. Range fields accept numbers and constant expressions such as -2*pi.
  3. Check Draw Custom Function or press OK to apply the palette settings.

For the full operator and function list, see Expression syntax.

Add, Edit, and Remove Curves

  1. Click Add... in the User-Defined Curves group.
  2. Choose y = f(x), Parametric, Polar, or Implicit.
  3. Enter the required expression(s), range, optional label and color, then click OK.
  4. Use the curve's checkbox to show or hide it. Select a curve and click Edit... to change it, or Remove to delete it.

Examples: a unit circle as a parametric curve is x(t)=cos(t), y(t)=sin(t), with range 0 to 2*pi. A unit circle as an implicit curve is x^2+y^2-1.

Draw Geometric Figures

Choose Draw > Draw Geometric Figures to open the geometric objects panel. Add a line segment by specifying its endpoints, or add a triangle by specifying vertices A, B and C. A line segment can optionally include a parallel line at a specified offset and a transversal through a selected point at an angle in degrees. Select an existing object to edit, remove or show/hide it.

Triangle options include custom vertex, side and angle labels; angle values; circumcircle and incircle outlines; perpendicular bisectors; angle bisectors; altitudes; and medians. The type constraints are General, Right-angled (angle C is 90 degrees), Isosceles (AC = BC) and Equilateral.

Save and Open Documents

Use the File menu or standard shortcuts: Ctrl+N for New, Ctrl+O for Open, and Ctrl+S for Save. A document stores drawing options, enabled built-in functions, curve definitions and geometric objects. Computed curve points are recalculated when a document is opened.

Print and Print Preview

Choose File > Print Preview to inspect the output or File > Print... to print. The application prints a single page and adds a document-name header and page-number footer.

Tips

  • Use pi and e in expressions and range fields.
  • Use a descriptive label and color for each user-defined curve.
  • Right-click to return to the exact default range after panning or zooming.

Limitations

The quick custom y=f(x) plot is sampled over its configured x-range; zooming does not extend that sampling interval. Added curves are sampled numerically, so narrow features may need a smaller range or denser sampling.

Examples

  • Parabola: x^2.
  • Gaussian: exp(-x^2).
  • Circle: parametric cos(t), sin(t), range 0 to 2*pi.

Notes: Function arguments and angles use radians. The coordinate view and the custom-expression sampling range are separate settings.

Tips: Start with a small coordinate range and widen it after confirming that the expression behaves as expected.

Warnings: Domain errors, such as division by zero, are not plotted. Logarithmic axes require positive coordinates.
