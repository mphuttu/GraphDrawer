Description

GraphDrawer is a Windows desktop application for exploring mathematical functions and geometric constructions on a two-dimensional coordinate plane. Plot built-in functions, write expressions, create parametric, polar and implicit curves, draw geometric figures, and print or save your work.

How to Use This Help

  1. Choose a topic from the Contents or Index tabs in the Help window.
  2. Use Related Topics links at the bottom of each topic to continue.
  3. Press F1 in GraphDrawer or choose Help > Help Contents to open this guide.

Tips

  • Start with Getting Started to plot your first graph.
  • Use the mouse wheel to zoom, drag with the left mouse button to pan, and right-click to restore the configured range.
  • For exact ranges and axis scale options, see Customization.

Limitations

GraphDrawer is a Windows MFC application. It requires the matching Microsoft Visual C++ runtime and MFC runtime for its architecture. Mathematical expressions are evaluated numerically; the program is not a symbolic algebra system.

Examples

Open the Draw Functions palette, enable Draw Custom Function, and enter sin(x)/x. The graph has a gap at x = 0, where the expression is undefined.
