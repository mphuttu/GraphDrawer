Description

This topic lists common drawing, installation, printing and Help issues and the steps to resolve them.

How to Use

  1. Find the symptom below that most closely matches what you see.
  2. Try the recommended steps in order.
  3. If the problem remains, note the GraphDrawer version, Windows version, architecture and exact expression or operation that triggered it.

Common Problems

A curve does not appear

  • Confirm its visibility checkbox is checked.
  • Check that the coordinate range includes the curve's domain and output values.
  • For an added curve, verify the expression and its range; undefined values are skipped.
  • On logarithmic axes, use positive coordinates.

The expression is rejected

Check parentheses, function names and the required variable. Use explicit multiplication, such as 2*x; implicit multiplication such as 2x is not supported. See Expression syntax.

The curve has gaps or spikes

Gaps are expected where an expression is undefined, for example division by zero, sqrt(-1), or log(0). Near a discontinuity, reduce the sampling interval by narrowing the curve's range or use a different expression.

Zooming or panning changed the view

Right-click in the coordinate view to restore the range from Draw Options. If the visible range is still unsuitable, enter new X and Y limits in Draw Options.

The application will not start

Install the Microsoft Visual C++ 2015-2022 Redistributable matching the application architecture. The application also requires the corresponding MFC runtime. On 64-bit Windows, a 32-bit build requires the x86 runtime.

The Help menu cannot open the manual

Confirm that Help\GraphDrawer.chm exists beside the installed application. If Windows displays a blocked-content warning, open the file's Properties and use Unblock if that option is present.

Printing is blank or clipped

Open Print Preview, check the printer and page setup, and ensure the axes and curves fall inside the configured range. GraphDrawer currently prints one page.

Tips

  • Test a complicated expression first with a simple range and fewer terms.
  • Use Print Preview before printing a final copy.
  • Save a copy before editing a document if you want to preserve its previous state.

Limitations

The application evaluates curves numerically and cannot prove whether a missing segment is mathematically absent or merely too narrow to sample. Some domain errors are silently omitted from the plotted line.

Examples

If 1/x appears with a vertical line across its asymptote, use a narrower range around the discontinuity or plot separate ranges on either side of x=0.
