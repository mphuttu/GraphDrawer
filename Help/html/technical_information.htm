Description

This topic documents supported platforms, expression evaluation, document storage, build requirements and the CHM help source layout.

How to Use

Use the sections below when deploying GraphDrawer, preparing a development build or diagnosing architecture and runtime requirements.

System Requirements

  • Windows 10 or later.
  • Microsoft Visual C++ 2015-2022 Redistributable matching the application's architecture.
  • The corresponding Microsoft MFC runtime. GraphDrawer uses dynamic MFC linkage.
  • For development: Visual Studio with the C++ desktop workload, MFC and a compatible Windows SDK.

Expression Syntax

The parser supports numeric literals, parentheses and these operators:

SyntaxMeaningExample
+, -Addition, subtraction, unary negation -x+2
*, /Multiplication, division 3*x, x/(x+1)
^Power; right-associativex^3
( )Grouping(x+1)^2

Constants: pi, e. Functions: sin, cos, tan, asin/arcsin, acos/arccos, atan/arctan, sinh, cosh, tanh, exp, log/ln, log10, sqrt, abs, sign, floor, ceil, and round. Trigonometric functions use radians.

Exponentiation binds more tightly than unary minus: -x^2 means -(x^2). Use (-x)^2 when the negative value itself should be squared. Multiplication must be explicit.

Curve Evaluation

GraphDrawer evaluates expressions numerically and samples points to draw lines. The quick custom expression is evaluated on a background thread. User-defined explicit, parametric, polar and implicit curves are also evaluated numerically. Undefined or non-finite values are omitted from the rendered curve.

Document Files

Documents use GraphDrawer's serialized MFC document format. The file stores display options, function visibility, curve definitions and geometric objects. Curve sample points are recomputed after loading. Save files using the File menu.

Build the Application

Open GraphDrawer.sln in Visual Studio, select Release and x64, then build the solution. The configured Release x64 output is:

D:\Projects\MFC\GraphDrawer\GraphDrawer\Release\x64\GraphDrawer.exe

Command-line build:

MSBuild.exe GraphDrawer.sln /m /p:Configuration=Release /p:Platform=x64 /t:Build

Build the CHM Help File

Help source files are under Help. Install Microsoft HTML Help Workshop, then run this from PowerShell at the repository root:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Help\build-chm.ps1

The compiled output is Help\GraphDrawer.chm. The script locates HTML Help Workshop in its standard installation folder and fails with an error if the compiler or output file is missing.

Build the Installer

Build the Release x64 application and CHM file first. Install Inno Setup 6, then compile Setup\GraphDrawer_Setup.iss with ISCC. The installer includes the executable, Help file and README. It does not bundle the Visual C++ Redistributable; deploy that runtime separately when required.

Tips

  • Use Release x64 for the standard installer build.
  • Rebuild the CHM before compiling the installer so it contains current help.
  • Use Print Preview to inspect the one-page print layout.

Limitations

GraphDrawer does not provide symbolic mathematics, plot export or multi-page graph printing. Numerical sampling can miss narrow features and does not establish mathematical continuity.

Examples

A quadratic is x^2; an exponential is exp(x); a circle is x^2+y^2-1=0 in Implicit mode.
