Description

This topic summarizes the documented GraphDrawer feature updates and fixes through the June 2026 release. The installer identifies the application as version 1.0.

How to Use

Review the entries below to understand when a feature or fix was introduced. For current usage steps, see Getting Started.

2026-06

Geometric figures

  • Added labelled line segments with optional parallel and transversal lines.
  • Added triangles with configurable vertex, side and angle labels, angle values and triangle type constraints.
  • Added circumcircles, incircles, perpendicular bisectors, angle bisectors, altitudes and medians.
  • Corrected angle arc placement at triangle vertex B.
  • Changed circumcircle and incircle rendering to outlines so they do not obscure the drawing.

Application icon

Updated the application and installer icons.

2026-05

Stability and correctness

  • Corrected print-preview header and footer sizing and placement.
  • Fixed a GDI pen handle leak during repeated custom-curve repaints by restoring the previous pen before releasing the custom pen.
  • Fixed worker-thread lifetime handling to prevent accessing a deleted MFC thread object.
  • Corrected expression exponent precedence so -x^2 evaluates as -(x^2).
  • Enabled constant expressions such as 2*pi and e^2 in curve range fields.
  • Added editing of existing user-defined curves.

Scale modes and rendering

  • Added Equal Scale, Free Scale and base-10 Logarithmic scale modes.
  • Updated screen drawing to use pixel coordinates and adjusted panning for each scale mode.

2026-04

  • Added polar curves of the form r=f(t).
  • Added implicit curves of the form f(x,y)=0.

Tips

  • Use the current topics in this Help file; older readme notes may describe intermediate development changes.
  • Check the application About dialog and installer properties for the installed version.

Limitations

This summary reflects the release information currently available in the project README. It is not a complete per-build change log.

Examples

To use the 2026-04 polar-curve feature, add a Polar curve such as r=1+cos(t) with an angle range of 0 to 2*pi.
